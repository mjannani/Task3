# Task 3: AI SEO Blog & Content Cluster Generator

## Project Overview
This project uses structured prompts to generate SEO-focused blog outlines, draft blog content and related-topic clusters for a local business website.

## Objective
Support useful, readable, business-focused content planning by mapping search intent, suggested keywords, blog structure and internal-linking ideas.

## Tools
- ChatGPT or another AI writing assistant
- Google Docs / MS Word
- GitHub
- Optional: Google Trends, Google Search Console, Ahrefs or Semrush for keyword research and validation

## Sample Business
Fictional business: Glow & Grace Salon, Chennai, Tamil Nadu.

## Deliverables
- SEO blog generator prompt
- Sample blog outline and article draft
- Content cluster with internal linking suggestions
- Prompt logic and testing documentation

## Usage
1. Replace the example business and topic with the actual business.
2. Validate keywords using appropriate SEO tools and current search results.
3. Generate the outline and draft using the prompt.
4. Fact-check the article and ensure it is useful and original.
5. Verify suggested internal links exist on the actual website before publishing.
6. Record real testing outcomes.

## Important
AI-generated keyword suggestions are hypotheses, not verified search-volume or ranking data. Do not claim a page will rank first or that unverified search volumes are factual.
